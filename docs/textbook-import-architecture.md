# 教材导入与内容保存
更新：2026-10-04。当前产品为 Tauri 桌面应用。

## 当前流程
1. 选择本地文件，按文件指纹检测已存教材及真实完成情况。
2. 未指定目录范围时裁剪前 30 页 PDF，由模型读取并提取目录，用户确认。章节立即保存于 documents.chapters_json，小目录不参与正文覆盖校验。
3. 内部换算物理页，按一级标题切分完整章节；全部待处理 PDF 先裁剪到任务临时目录，之后启动连续 Worker。
4. 固定 Agent 池读取当前章节 PDF。文字页直接读取，扫描页按需渲染查看，不运行 OCR 或 MinerU，不预先上传正文图片。详见 [PDF 文件流程](textbook-pdf-file-flow.md)。
5. 模型根据本章实际内容选择六个小工具增查改删，有则提交、无则省略，不为凑齐类别生成内容。每次调用先校验并暂存；模型轮次正常结束、全部调用处理完且至少提交一类有效内容、没有未修正的操作错误后，一次事务保存内容、全局新词、索引和完成状态。复习章可以只有练习，总结章可以只有知识点，词汇章可以只有词汇。
6. 按实际存在的知识点、词汇、文章、句子和练习展示，空分类隐藏。

## 责任边界
- PDF 模块只准备裁剪文件与阅读入口；会话池负责工具注入、发送与事件消费。
- 原生工具负责当前轮次权限、内容格式校验及独立缓冲区；查询返回已有内容与暂存变更，短引用仅当前尝试有效。SQLite adapter 负责全局词汇去重、内容身份和整课事务。
- 调度器控制模型和存储重试。暂时性数据库失败只重试保存，不重新要求模型生成。
- 模型只填写内容，系统负责用户/教材/章节归属、ID、排序和时间。未知字段、非法题型或不对应的答案返回具体内容字段错误。
- 结束、取消或超时后的工具调用拒绝接收，本轮暂存丢弃。未正常完成的章节不能提交；已保存版本保留，重新提取也只在最终事务替换旧内容。保存失败不会残留部分内容或全局新词。
- 本轮模型输入是实际发送的消息，Worker 的线程历史继续复用；不宣称已经清空历史或知道引擎全部隐藏上下文。

## 工具与存储
[教材学习内容表与工具](textbook-learning-tables.md) 列出七张表、全部字段、简单参数、等级去重、评分记录和迁移方式。

原生引擎接收实际工具说明和参数契约；章节提示词只点名，不重复粘贴 JSON Schema。旧 library_commit_lesson_knowledge 及其专属规范化、目录覆盖和来源引用校验已删除。

工具说明明确选择题/排序题提供 options，排序答案覆盖全部词块及重复次数；可选字段没有值直接省略，不填空字符串。已有相同内容先读取后修改；短引用只属于当前章当前尝试，重试后通过 read 获取新引用，不沿用上一轮 ref。这些说明解释现有契约，不增加内容必交类别。

五类内容表为事实源。documents 只保留教材元信息和章节清单，不重复持久化全书 AST 或逐行正文。显式结构化文件导入和已有读取接口可转换成视图，但不另保存一套内容。FTS 由学习内容表重建。

v37 一次迁移已有内容，保留可用内容身份、例句、译文和答案，小节内容归入保留章节；随后删除旧五张教材表和旧回填脚本。已发布迁移不改写，不保留旧运行兼容入口。

## 模型监视
弹窗默认显示本次模型输入、会话声明、调用参数、校验反馈与事务回执；历史交互折叠。工具回执明确区分“已暂存，等待整课提交”和“暂存内容已随整课保存”。材料准备只显示 PDF 文件、页数和阅读命令；模型部分展示实际公开读取/工具事件。查询数据库当前内容读取真实学习表，附读取时间。

仅记录实际捕获的公开模型事件；引擎内置提示词、未提供的历史压缩和隐藏内容不臆造。记录失败不得篡改真实保存结果。

## 配置和验收
模型、思考等级、会话数、首响应/停滞超时和修正/存储重试预算均保留用户显式配置。

本机阅读需要 Node.js 与经校验的 PDF 原生库；不需要 Python、OCR 模型或 MinerU Token。任务结束、失败或取消先关闭会话再清理临时文件。

集成测试使用真实 SQLite、Gateway HTTP、原生 PDF 阅读器与桌面组件；模型输出为受控边界。覆盖五类写入、全局词复用、用户隔离、会话复用与迟到拒绝、保存重试、迁移回滚、重复启动、监视展开折叠和读取结果。测试通过不能证明真实模型对教材的语义整理质量。

正式门禁：bun run typecheck、bun run test:all。
