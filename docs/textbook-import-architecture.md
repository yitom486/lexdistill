# 教材导入与内容保存
更新：2026-10-03。当前产品为 Tauri 桌面应用。

## 当前流程
1. 选择本地文件，按文件指纹检测已存教材及真实完成情况。
2. 探测目录范围，模型提取目录并由用户确认。章节立即保存于 documents.chapters_json，小目录不参与正文覆盖校验。
3. 内部换算物理页，按一级标题切分完整章节。扫描正文默认本地 OCR，用户可选择 MinerU 云端或已部署的本机 V1 服务；失败不自动切换。数字原生 PDF 直接提取文字。本地 OCR 优先逐页识别行，避免表格 Markdown 列重排；每批最多 30 页，长章节合并后才作为一个模型任务进入有界队列。
4. 固定 Agent 池并发消费章节材料，Worker 复用会话。章节提示词包含语种、标题、解析后的文字/表格和工具名称，不含新内容 ID、页码、sourceRefs、coverage 或 JSON 模板。不发送正文原页图片。
5. 模型通过六个小工具多次增查改删；每次调用先校验并暂存。模型轮次正常结束、全部调用处理完后，核对知识点、词汇、练习均已提交有效内容，再一次事务保存内容、全局新词、索引和完成状态。文章、句子、整理材料可省略。
6. 按实际存在的知识点、词汇、文章、句子和练习展示，空分类隐藏。

## 责任边界
- 解析模块只产生章节材料；会话池负责工具注入、发送与事件消费。
- 原生工具负责当前轮次权限、内容格式校验及独立缓冲区；查询返回已有内容与暂存变更，短引用仅当前尝试有效。SQLite adapter 负责全局词汇去重、内容身份和整课事务。
- 调度器控制解析、模型和存储的独立重试。暂时性数据库失败只重试保存，不重新要求模型生成。
- 模型只填写内容，系统负责用户/教材/章节归属、ID、排序和时间。未知字段、非法题型或不对应的答案返回具体内容字段错误。
- 结束、取消或超时后的工具调用拒绝接收，本轮暂存丢弃。未正常完成的章节不能提交；已保存版本保留，重新提取也只在最终事务替换旧内容。保存失败不会残留部分内容或全局新词。
- 本轮模型输入是实际发送的消息，Worker 的线程历史继续复用；不宣称已经清空历史或知道引擎全部隐藏上下文。

## 工具与存储
[教材学习内容表与工具](textbook-learning-tables.md) 列出七张表、全部字段、简单参数、等级去重、评分记录和迁移方式。

原生引擎接收实际工具说明和参数契约；章节提示词只点名，不重复粘贴 JSON Schema。旧 library_commit_lesson_knowledge 及其专属规范化、目录覆盖和来源引用校验已删除。

五类内容表为事实源。documents 只保留教材元信息和章节清单，不重复持久化全书 AST 或逐行正文。显式结构化文件导入和已有读取接口可转换成视图，但不另保存一套内容。FTS 由学习内容表重建。

v37 一次迁移已有内容，保留可用内容身份、例句、译文和答案，小节内容归入保留章节；随后删除旧五张教材表和旧回填脚本。已发布迁移不改写，不保留旧运行兼容入口。

## 模型监视
弹窗默认显示本次模型输入、会话声明、调用参数、校验反馈与事务回执；历史交互折叠。工具回执明确区分“已暂存，等待整课提交”和“暂存内容已随整课保存”。解析只看最终材料，不展示上传/轮询时间线。查询数据库当前内容读取真实学习表，附读取时间。

仅记录实际捕获的公开模型事件；引擎内置提示词、未提供的历史压缩和隐藏内容不臆造。记录失败不得篡改真实保存结果。

## 配置和验收
模型、思考等级、会话数、解析方式/并发、本地服务地址、超时和重试预算均使用现有显式配置。不硬编码教材名、页码或等级。

本地 OCR 无需 MinerU Token 或 MinerU 服务，首次运行按现有运行时管理器准备 OCR 库与模型。只将识别文字发给后续模型，不发送正文图片。当前原生推理不支持中途终止当前批次；取消或超时停止消费，迟到结果不进入模型与数据库。升级时只将旧解析方式偏好改为用户批准的本地 OCR，其他偏好保留，之后的手动选择继续持久化。

集成测试使用真实 SQLite、Gateway HTTP、原生 OCR 与桌面组件；模型及云端解析输出为受控边界。覆盖五类写入、全局词复用、用户隔离、会话复用与迟到拒绝、保存重试、迁移回滚、重复启动、监视展开折叠和读取结果。测试通过不能证明真实模型对教材的语义整理质量。

正式门禁：bun run typecheck、bun run test:all。
