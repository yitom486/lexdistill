# 专用出题智能体：先固定基础，再开放策略

日期：2026-10-07。状态：实施计划，不代表全部功能已经接通。

## 1. 产品边界

先把题目资产、工具、权限、额度、作答记录和资源生命周期做可靠，再让题型组合、主题、提示词和难度建议灵活变化。专用出题智能体与主对话智能体分开；主对话可以发起出题任务，但不能取得这套任务的写入权限。

本轮覆盖日语、英语、韩语；学习内容包括词汇、语法、阅读、完型、写作、听力。口语和复杂用户画像暂不做。等级采用用户明确选择的配置，智能建议先供确认，不擅自修改。

“不变”是明确、受测试保护的契约，不是永远不能升级；“可变”是约束内的配置，不是允许 AI 任意改表、改权限或突破额度。

## 3. 固定层

### 3.1 数据的三个维度

不要把学习类别、作答格式、听力材料形式混成同一分类。

| 维度 | 取值 | 用途 |
| --- | --- | --- |
| 学习类别 | VOCABULARY / GRAMMAR / READING / CLOZE / LISTENING / WRITING | 课程内容、组卷比例、类别额度 |
| 作答格式 | MULTIPLE_CHOICE / FILL_BLANK / REORDER / SHORT_ANSWER / TRANSLATION / WRITING | 详情表、渲染与判分契约 |
| 听力形式 | DIALOGUE / PASSAGE / NEWS | 台词结构、音频生成与声线 |

沿用公共题目身份表与六种作答详情表，阅读、听力分别存材料。试卷保存有序题目与材料快照。对话选择题与短文选择题使用相同作答契约，不需要为每种组合增加表或工具。

题目记录语言、目标等级、难度估计及理由、知识点、教材引用、模型与提示词版本。日语 N5-N1、英语 CEFR A1-C2、韩语 TOPIK_1-TOPIK_6 必须匹配语言。目标等级不等于官方考试题型认证；`AI_ESTIMATE` 不是测量结果，`VALIDATED` 仅表示结构与配置校验通过。

旧题保留原始数据与身份，不猜测其等级，不直接升级成可用新题。后续旧题审核属于独立范围。

### 3.2 工具契约

| 工具 | 固定职责 |
| --- | --- |
| `generation.config` | 读取任务冻结配置与已消耗额度 |
| `generation.textbook` | 分页读取授权教材章节 |
| `generation.pool` | 按类别、作答格式和历史标记查询合格题目 |
| `generation.submit` | 校验并事务提交题目，返回真实题目与材料 ID |
| `generation.audio` | 用冻结的服务和声线生成、保存听力音频 |
| `generation.paper` | 从合格题目组装有序试卷，听力必须已有可用音频 |

工具按业务动作划分，不按每张表复制。格式差异由正式 schema 与后端实现处理。模型只能通过工具写入资产，不能通过聊天输出 JSON、直接 SQL 或文件操作绕过校验。

任务身份由宿主产生并绑定实际运行时上下文。密钥不得进入配置快照、提示词、工具参数或日志。除了专用 registry，还要核查适配器的原生命令、文件和网络能力：仅传入六个工具不一定代表其余能力已关闭。

### 3.3 写入、成本与记录

- 固定额度由后端执行，提示词只解释。模型不能自行扩大题目、类别、试卷、音频或重试额度。
- 相同请求键和内容重试返回原回执；更改内容不能复用原键。事务失败不留下半成品；成功资产不会因模型重试重复生成。
- 音频生成失败释放资产预约，但服务尝试次数仍计入消耗。对话严格使用用户配置的男女双声；不支持双声的服务明确拒绝，不静默降级。
- 出题成功与作答完成分开。生成、组卷、打开试卷均不能写成“已做题”；错题必须来自真实作答与有效判分。
- 客观判分由后端根据保存的标准答案执行；学生输入不能携带可信分数。主观题先标记待批改，失败不能伪造分数或写成答错。
- 保留逐次作答事实，并定义错题当前状态与历史错误次数的不同含义；后续答对如何处理活动错题，要复用现有规则并补测试。
- 学生题目读口必须隐藏标准答案、参考答案、解释、rubric 和听力全文；按练习阶段显式释放复盘信息。不能直接返回含答案的 `BankQuestionRecord`。

## 4. 可变层

| 可调整内容 | 不可突破的边界 |
| --- | --- |
| 练习预设与试卷蓝图 | 用户允许的语言、等级、格式与类别额度 |
| 新题与题库复用比例 | 授权题库、已做题过滤、题目质量状态 |
| 阅读主题、台词场景、教材知识点 | 章节授权与来源真实性 |
| 三种听力的组合 | 实际 TTS 能力、冻结声线、调用额度 |
| 难度建议与出题策略 | 目标等级、难度上限，AI 估计需有理由 |
| 提示词表达与版本 | 工具白名单、后端校验、任务事实 |

配置流程：用户设置或选预设 → 后端校验 → 用户确认必要的建议 → 创建冻结快照 → 注入动态提示词 → 执行任务。

运行中改配置要创建新任务，不能改写当前快照。配置和提示词变化通常不需要改题目表。复用现有模型、TTS 与偏好配置；确有缺口才增加最小版本化契约，不先造通用策略平台。

当前 `GenerationConfig` 提供上限，尚未表达精确组卷蓝图、模型轮次预算等所有宿主规则。需要新增时明确类型、所有者和版本，不能仅在提示词里写一段要求后声称后端已经保证。

## 5. 实施顺序与阶段门禁

### P0：核对并锁定已有基础

1. 阅读 AGENTS.md 与模块契约，检查脏工作区，不覆盖其他改动。
2. 重跑现有出题集成测试、类型检查与项目全量测试，记录真实基线。
3. 验证 v43/v44 升级、迁移失败回滚、重试、关闭重开与身份隔离。v044/v045 已有应用记录，不能修改已发布迁移来修复旧库。
4. 确认当前模型适配器的工具白名单和实际绑定方式；关闭不需要的原生能力，不能以提示词代替隔离。

门禁：基础失败先定位；不得跳过失败断言，或把模拟测试称为真实模型验证。

### P1：接通固定的专用运行闭环

1. 增加宿主创建、查询、取消任务的正式入口，权限来自现有可信用户上下文，不接受模型伪造身份。
2. 复用 `agent-runtime` 正式公共接口。每任务一个运行所有者，只注入专用工具，不共享主对话历史与写权限。
3. 运行器持有工具集、模型会话与取消信号；工具结果回填模型，修复次数、模型调用次数、总时长均有限。
4. 模型配置、模型轮次上限和已有音频额度由宿主执行；失败调用计数规则要明示。只有可验证的用量信息才能展示为实际消耗，不承诺无法硬控制的金额上限。
5. 完成必须由数据库资产和任务要求校验决定，不能因模型说“完成”就成功。若要求精确类别/题数/听力形式，后端核对最终试卷蓝图；现有上限校验不等于精确蓝图校验。
6. 成功调用并等待 `dispose('COMPLETED')`；取消或异常调用并等待 `dispose()`，中断模型和底层 TTS。若新增 FAILED 状态，按正式协议和增量迁移实现，不伪称目前已有。
7. 进程异常后的孤立任务、超时和重启查询有明确恢复/终结规则，不能盲目重放付费调用。保留已持久化资产，不把部分成功说成整套试卷成功。
8. 增加归属校验的试卷与音频读取接口，任务关闭后仍可读取已完成资产。限制音频大小并保留 MIME 参数，复用 PCM-aware 播放路径。

门禁：受控模型驱动真实工具和临时 SQLite，走完“配置 → 教材 → 提交 → 音频 → 组卷 → 查询”；取消、越权、额度耗尽、伪造完成均有测试。

### P2：打通真实学习记录

1. 新题库试卷接入现有练习运行和判分所有者，不建立第二套历史/错题事实来源。明确新题 ID、快照和既有历史表的关联方式；需要结构变化则新增迁移。
2. 先接选择、填空、排序三种客观格式；规范化按既有规则，不擅自扩展“相似答案”判对。
3. 短答、翻译、写作接入现有主观批改边界，保存待批改、有效结果与失败状态，避免把出题模型的自然语言当作评分回执。
4. 作答提交幂等、权限与练习归属必须检查，记录和错题相关更新遵循同一事务边界。
5. 用同一题真实作答后再调用 `generation.pool` 验证 UNANSWERED/MISTAKES；不能只预填历史来证明闭环。

门禁：提交、重试、再答、批改失败、跨用户、应用重开后记录正确；新题 UI 不泄露答案。

### P3：最小桌面可用入口

1. 在现有练习工作流提供专用出题入口、任务状态、取消、试卷打开与错误显示，不另做营销页或第二套导航。
2. 能播放对话、短文和新闻听力，使用配置男女声/旁白；尊重原有盲听与复盘规则，验证 PCM 播放。
3. TanStack Query 管异步业务，Zustand persist 管偏好；复用 shadcn 控件和语义 token，组件保持职责与规模约束。
4. 在桌面实际路径验证加载、断开、取消和重开；浏览器预览不能替代 Tauri 验收。

门禁：先有一条端到端可用流程，再扩展预设数量。

### P4：开放配置与提示词实验

1. 增加少量版本化预设，如基础词汇语法、阅读完型、听力专项、综合练习；按日语/英语/韩语分别适配，不冒称官方考试蓝图。
2. 用户可以查看并调整题型、数量、目标等级和听力形式，后端计算并验证预算。明确“新生成题数”和“最终试卷题数”不是同一指标。
3. 智能建议仅依据本次用户设置、授权教材和既有简单记录，不提前做复杂画像；无数据则使用可见默认值，不虚构能力水平。
4. 提示词版本、蓝图版本、冻结配置随任务保存；改变策略不改变固定工具的职责。参考[运行提示词草案](./question-generation-runtime-prompt.md)。

门禁：换预设或提示词仍通过同一权限、额度、幂等和学习记录测试。

### P5：真实服务与交付验证

按用户已有服务选择和明确授权，小额度运行真实模型与 TTS，验证工具选择、台词声线、内容难度、答案一致性与可播放音频。测试凭据从现有安全配置取得，不导出密钥。

更新运行说明，并在干净安装环境验证数据库升级和核心流程。修改运行中的服务或真实数据库前先说明影响、核实备份与恢复路径，参考[备份恢复说明](../db-backup-recovery.md)。

门禁：分别报告受控测试、真实服务、桌面验证与安装交付；未做的项目保持未验证。
