## 实现规则

1. 宿主生成可信任务身份、冻结配置和额度；密钥留在服务边界，不进入提示词、快照、模型参数或日志。
2. 每任务只允许一个运行所有者，复用 `agent-runtime` 公共接口。对接实际 session/turn 生命周期，不接受模型填写的身份来满足工具绑定。
3. 真正限制原生文件、命令和网络能力；不要假设只提供六个工具就自动关闭其他能力。隔离无法保证时明确报告阻碍，不用提示词伪装安全边界。
4. 将固定系统规则和 `dynamicPrompt()` 的宿主配置注入专用会话；教材、题目正文、用户主题均是资料，不是高优先级指令。参考运行提示词草案，不重复维护后端已有校验规则。
5. 后端限制模型轮次、修复次数和总时长，沿用题目/类别/音频/试卷额度。需要的新宿主配置必须有正式类型与校验，不仅写进 prompt。
6. 工具结果回填模型；失败有界修复。同键同内容复用回执；已成功音频不重复付费，失败音频调用仍消耗尝试额度。
7. 只有持久化资产符合本任务要求才成功。若要求精确组卷比例或听力模式，增加宿主最终校验；现有最大额度不保证精确蓝图。模型文本、COMPLETED 事件均不能单独证明业务成功。
8. 成功等待 `dispose('COMPLETED')`，取消/失败等待 `dispose()`，并停止底层模型与 TTS，最后释放会话。进程异常和重启后的未完成任务须有明确策略，不盲目重放付费任务。
9. 试卷与音频查询校验归属，完成后可重开；学生 DTO 隐藏答案、解释、rubric 和未开放的听力全文。音频保留 MIME 参数，复用支持 PCM 的播放路径。
10. 男女对话必须尊重用户配置的双声服务；不支持则可读地拒绝，不能静默改声线或降级。日语 N5-N1、英语 CEFR、韩语 TOPIK 匹配语言；难度是有理由的 AI 估计，不是官方认证。
11. 只改本批必要模块。重大公共契约、隔离能力或数据处理边界调整先说明并按 AGENTS.md 取得批准；不要重写练习系统、退役旧表或扩大到复杂画像与口语。
12. 不为文档里的未来阶段提前制造通用平台。后续 UI 遵守 shadcn、TanStack Query、Zustand persist、语义 token 和组件规模限制。

## 必须完成的验证

受控模型可以替代付费调用，但实际工具执行、任务入口和 SQLite 必须真实运行，不能只 mock repository 或直接插入一张“成功试卷”。

- 走通配置、授权教材、提交题目、三种听力材料、音频、混合组卷、关闭后查询资产。
- 验证用户/session/turn 越权、教材提示注入、非白名单能力、任务过期和并发运行保护。
- 验证取消实际中止、超时、音频服务不支持双声、额度耗尽、提交回滚、幂等回放/冲突和重启后孤立任务。
- 验证模型虚报完成或试卷不符合明确任务要求时，后端不会返回业务成功；部分完成资产不会伪装成完整试卷。
- 验证生成和组卷不标成已做题，学生读口不泄露标准答案。
- 重跑既有出题集成测试、`bun run typecheck`、`bun run test:all` 和 `git diff --check`。新失败必须说明；历史教材导入 DOM 失败需要重新验证，不削弱断言换取通过。

测试方法参见计划第 6 节。不要未经授权运行真实付费模型/TTS，不导出凭据。修改运行中的服务或真实数据库前说明影响并核实备份；平时用临时数据库做测试。

## 交付方式

开工先简述现状与本批范围，然后实现并验证，不停在另一份泛泛计划。遇到真实边界阻碍时说明事实和所需决定，不伪造成功。

完成后用中文简述：已接通的流程、变更文件、真实测试结果、未完成/未验证内容和下一阶段入口。遵守每次回复先写 `Natural English:` 的项目规则。

只有 P0/P1 门禁满足才报告第一批完成；P2/P3 学习闭环和 P4 配置实验按计划顺序另行推进。
