# 教材原生工具提交

更新：2026-10-04。输入及文件生命周期见[本机 PDF 流程](../textbook-pdf-file-flow.md)，存储字段见[内容表与工具](../textbook-learning-tables.md)。

章节会话通过 AgentAdapter 的 tools 注册词汇、知识点、文章、句子、练习与整理材料独立工具。模型根据本章实际内容多次增查改删，只填学习内容；身份、数据库 ID、排序、时间和事务由系统负责。纯复习/总结/词汇章无需凑齐类别。

原生协议带参数 Schema，提示词只给当前任务、PDF 路径、阅读命令、目录参考与工具名称，不重复大段 Schema 或示例。知识点 explanation/aiExplanation、词汇 explanation 和句子 explanation 使用 Markdown；独立例句、译文、题目保留结构化字段，不混入 Markdown 正文。

每轮校验后暂存于独立缓冲区，工具回执只表示暂存。模型正常结束且操作错误已修正后，系统按章一次事务写入内容、全局新词、索引和完成状态。数据库暂时失败仅重试该候选的保存，成功事务回执才表示已保存。

连续 Worker 保留历史；当前任务与原生 turnId 绑定，短引用只在当前尝试内有效。旧轮次、迟到写入和结束后的调用拒绝。普通章节结束不重建线程，故障会话才替换。不能据此保证模型语义绝对正确。

旧 library_commit_lesson_knowledge、MinerU 块、sourceRefs、coverage 和图片附件预算已移除。监视页面展示实际模型输入、公开事件、工具参数/回执和事务结果；不臆造隐藏提示词或历史压缩。
