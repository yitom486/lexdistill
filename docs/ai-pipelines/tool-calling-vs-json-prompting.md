# 教材章节原生工具提交

更新：2026-10-01。完整实现与验收见[教材导入架构](../textbook-import-architecture.md)及[集成验收记录](../textbook-import-verification.md)。

正文会话通过 `AgentAdapter.createSession({ tools })` 注入唯一章节提交工具。提示词仅提供本次章节任务、目录和内容，以及模型实际可见的工具名称。参数说明、来源枚举与题型结构放在工具定义中；原生协议仍携带参数 Schema，提示词不再复制 Schema、JSON 模板或静态示例。

执行入口检查用户、会话和实际原生轮次绑定；document/lesson/assignment 身份由系统提供，模型只提交 content。独立提交服务检查格式、目录覆盖和习题答案结构，反馈原始字段路径及所有可安全核对的问题。每轮工具修正预算和后续新轮预算分别由用户配置。

通过校验的候选交给 Repository，规范 AST、提交身份和派生行在同一事务保存。成功回执只在事务提交后返回；重复提交返回原结果。暂时性存储故障只重试保存候选。

本轮已删除普通文本 JSON 解析与回填入口。原生工具调用本身也可能包含错误、缺项或错误来源标记，因此仍须运行时校验；工具调用不能保证正文语义正确。

固定数量会话跨章节复用。当前 Turn 结束后解除绑定再分配下一章；此前章节或尝试的 ID 不可继续写入。运行时故障才触发会话替换并记录原因，正常章节不会重建上下文。

输入包含本次实际目录路径、子树、顺序和物理页码；独立导入部分也作为任务，不靠课名正则识别。所有内容及 AI 例句用 tocId 关联当前目录。原生工具明确正文、译文、生词独立 AI 讲解、知识点两类讲解与例句的位置，提示词不复制参数 Schema。

MinerU 升级后，章节输入携带当前页块、表格行和原书物理页，表格/图片页以 PNG 附件进入 Turn。工具要求 TEXTBOOK 内容在有解析块的任务中提供 `sourceRefs`；模型只引用真实块和可选行，系统映射物理页，未知块/越界行拒绝。不能跨页串行合并词条；读音/音调需核对原页，无法确认的音调省略。引用随规范内容保存，不把解析原文落成第二份教材底稿。AI 补充练习仍可独立生成并注明来源。

模型停滞超时撤销本次提交资格并中断 Turn；下一次生成前关闭发生运行时故障的会话，避免尚未收尾的流污染新的轮次。仅此故障恢复会替换线程，普通字段纠正仍复用。监视弹窗展示实际输入、工具注册声明、参数、校验和事务记录；候选与数据库当前版本分别标明。
