# 本机私人教材 PDF 读取验收

更新：2026-10-04。真实私人教材不进入 CI 或仓库 fixture；整本质量由用户检查。

1. 用 bun run dev:web 监督器或桌面应用启动服务，确认 Gateway 身份正常，Node.js 可用。
2. 选择教材，目录范围留空，验证前 min(30, 页数) 页裁剪后交给目录会话。查看运行详情中的实际输入路径、阅读命令、目录草稿和真实目录结束页。
3. 目录不存在于该窗时手动指定范围；校对父子层级、印刷页与物理页映射，再保存。
4. 启动章节处理，检查全部文件先准备、连续 Worker 读取本轮文件、原生工具暂存与事务成功回执。测试不同页数和含扫描页的章节；不要求每章内容类别齐全。
5. 检查取消/失败保留已保存章节，活动会话关闭后删除任务文件，原 PDF 保留；重试只处理未完成章节。
6. 教材主页选第二课及其他章节，核对例句、译文、知识点 Markdown、TTS 和各类练习。

不再配置 MinerU、OCR、ONNX Runtime 或 Python。文字层为空时 Agent 按需渲染查看，不是把原 PDF 当二进制附件上传。详见[当前文件流程](textbook-pdf-file-flow.md)。

旧 live-corpus-map 脚本仍只用于原生文字/书签结构诊断，不是产品目录识别流程。失败记录只记页码、标题、错误代码和阶段；不复制私人课文/页面进仓库。
